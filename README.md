# Scarabelot — novo site

Protótipo do novo site institucional e comercial da Scarabelot Implementos.

## Stack
- Next.js 16
- React 19
- TypeScript
- CSS responsivo
- Lucide React

## Rodar localmente

```bash
npm install
npm run dev
```

## Primeira fase
- Home responsiva
- Identidade azul, vermelho e branco
- Hero comercial
- Protótipo de exploded view interativo
- Linha inicial de produtos
- Blocos de financiamento, entrega, suporte e história
